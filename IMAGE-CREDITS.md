## Notes on sourcing method

- **Part B files** (`services-03/04`, `facility-07..11`, `cert-01/02`): Source = the exact
  `images.unsplash.com` CDN URL (with the original crop/size query string) fetched with `curl`.
- **Pre-existing local files** (`about-*`, `rd-*`, `product-*`, `facility-01..06`,
  `services-01/02`, `contract-*`, `private-label-*`, `capsule-*`): matched to the attribution
  comment sitting directly above/below each `<img>` tag in
  `/home/zedfaceless/Downloads/new-landing-page.html` (found via
  `grep -n -i 'Unsplash' new-landing-page.html`). Where the comment only gave the CDN asset ID
  (e.g. `photo-1532187863486-abf9dbad1b69`, no page slug), Source links to the CDN image
  directly (`images.unsplash.com/photo-<id>`) since that ID does not resolve as an
  `unsplash.com/photos/<id>` page (confirmed via `WebFetch`, all 404). Where the comment gave a
  full page URL (e.g. `https://unsplash.com/photos/2SBCq0WSKbs`), Source is that page URL and a
  photographer name was fetched from the page directly.
- **Photographer name**: one `WebFetch` attempt per unique photo, per the sourcing brief. 11 of
  43 lookups (all the ones with a real page-slug URL) resolved to a name straight from the
  Unsplash page. The other 32 (raw CDN-ID references, which have no resolvable page URL) fall
  back to `Unsplash contributor (see Source URL)` — no name was guessed or fabricated.
- **`home-hero.jpg`**: not stock. The source HTML's comment directly above the hero `<img>`
  states this is Ally Nutra's own encapsulation-machine photography, referenced from their live
  site and saved locally as `hero-bg.jpg` — not sourced from Unsplash.
